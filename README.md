# 第41屆行義蘭姐童軍專科考驗暨聯團露營報名及表件上傳系統

本系統為專屬「臺中市第 41 屆行義蘭姐童軍專科考驗暨聯團露營」打造之線上報名與表件繳交管理平台，提供各參賽學校代表與大會管理人員無紙化、高效且直覺的數位作業流程。

---

## 📋 系統功能簡介

### 1. 學校代表端功能
* **教育網域驗證登入**：支援 Google 帳號授權，保障各校報名代表身份真實性與通訊公信力。
* **代表資料維護**：各校報名代表人可隨時查詢與維護自身聯絡人姓名、聯絡電話及相關備註。
* **四項必備表件線上繳交**：
  * 團體報名表 (Excel / PDF / ODS)
  * 學校核章報名掃描檔 (PDF / 圖片 / 文件)
  * 領隊 Safe from Harm 防制傷害研習證書 (PDF / 圖片 / 文件)
  * 繳費證明與開立收據抬頭 (PDF / 圖片 / 表格文件)
* **表件規格防護機制**：內建單檔容量限制與格式校驗，預防檔案損毀或傳輸中斷。
* **即時審查進度追蹤**：具備視覺化審查狀態與即時退件/補件原因提示，方便代表隨時掌握進度。

### 2. 大會管理端功能
* **報名期程控管**：可彈性設定報名起訖時間，系統自動比對伺服器權威時間，截止時自動安全鎖定。
* **各校進度總覽儀表板**：即時匯總全市各校表件繳齊率、已繳齊學校清單與待補件學校名單。
* **線上表件審核與批改**：支援管理員快速檢視、下載各校繳交之檔案，並提供核定合格或退件補件指導意見。
* **下載範本與上傳欄位自訂**：可於後台彈性維護官方報名表件範本連結與各項上傳欄位說明。
* **安全稽核日誌 (Audit Logs)**：詳實記錄代表與管理員之各項異動操作歷程，保障活動資料溯源之完整性。

## 🔒 系統架構與安全規範

* **前端架構**：React 19、TypeScript、Tailwind CSS、Vite。
* **資料與驗證服務**：Firebase 雲端架構與嚴謹的安全規則（Security Rules）。
* **資安防護**：全系統實作 XSS 字元過濾、台灣電話號碼格式驗證，以及多重權限隔離防護。
